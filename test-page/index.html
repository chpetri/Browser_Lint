Browser Lint – Testseite

Feld anklicken, Alt+Shift+L drücken (oder Icon klicken), danach Strg+Z testen. Neu laden setzt alles zurück.

1. textarea

Alle fünf Regeln. Ein Strg+Z stellt den Originaltext wieder her.

2. input type=text / type=email

E-Mail-Felder entfernen Leerzeichen selbst. Erwartet: „Keine Korrekturen nötig“ ohne Fehler.

3. input type=password

Wird nie angefasst. Erwartet: „Dieses Feld wird nicht unterstützt“.

4. Kontrolliertes Feld (wie React)

Ein direktes el.value = x würde hier ignoriert. Der State darunter muss sich mitändern.

5. contenteditable wie Gmail

Zeilen als <div>, Leerzeilen als <div><br></div>, doppelte Leerzeichen als „&nbsp; “.

Fett/kursiv bleibt erhalten, auch bei Leerzeichen über Knotengrenzen. Code, Zitat und der Chip (contenteditable=false) bleiben unverändert.
